# Délégations

Historique du travail des agents de délégation autonomes sur le repo `suddenly-muses`.

## Objet

Chaque agent autonome (ex. `hermes`, agent de test) produit du travail qui doit être
tracé ici : ce qui a été délégué, ce qui a été fait, le verdict, et la suite décidée.
But : garder une mémoire auditable des délégations, distincte de :

- `aidd_docs/tasks/` — plans de tâches (entrée)
- `aidd_docs/reviews/` — challenge reports (revue de plans)
- `aidd_docs/memory/` — mémoire projet (vérité long terme)
